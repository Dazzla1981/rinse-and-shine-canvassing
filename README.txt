RINSE & SHINE SURREY — CANVASSING PWA

This folder is the hosted/installable version of the working v1.8 app.

FILES
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

IMPORTANT
A PWA must be served from HTTPS (or localhost). Opening index.html directly from Files/file:// will NOT enable the service worker and may still block the free address lookup on iPad.

FREE HOSTING
Upload the contents of this folder to any static HTTPS host. Once hosted:
1. Open the HTTPS address in Safari on iPad/iPhone or Chrome on Android.
2. iPad/iPhone: Share > Add to Home Screen.
3. Android: browser menu > Add to Home screen / Install app.

DATA
The app still stores its database locally in the browser. Use Export Backup before moving away from an existing downloaded-file version. Cross-device syncing is not included yet.
